# Альфред (Alfred) — персональный ИИ-ассистент с графовой памятью

> **Альфред** — это не просто чат-бот. Это персональный ИИ-ассистент, который запоминает факты, цели и связи между событиями, храня их в виде графа. Его «мозг» можно визуализировать в Obsidian, а работает он на Python через Groq API.

## 🧠 Что такое «Альфред»?

«Альфред» — это эксперимент по созданию ИИ-ассистента с **долговременной памятью**. В отличие от стандартных чатов, где контекст теряется после закрытия окна, Альфред строит **граф знаний** о пользователе. Он извлекает из диалога новые факты (люди, цели, эмоции, навыки, события), добавляет их в граф и синхронизирует с локальным хранилищем Obsidian.

**Главная фишка:** ты можешь открыть Obsidian Graph View и увидеть «мозг» Альфреда как интерактивную паутину связей.

## ✨ Ключевые особенности

- **Графовая память:** Узлы (факты) и рёбра (связи) хранятся в JSON. Это позволяет ассистенту «понимать» контекст, а не просто помнить последние сообщения.
- **Синхронизация с Obsidian:** Граф автоматически превращается в Markdown-файлы с wiki-ссылками `[[узел]]`. Открывай Obsidian и смотри на паутину.
- **Динамическое обновление:** Альфред анализирует диалог и сам добавляет новые узлы и связи без ручного вмешательства.
- **Работа через Groq API:** Быстрая и бесплатная обработка запросов к LLM (Llama 3.3 70B).
- **Локальное хранение:** Твои данные (память) хранятся локально в JSON-файле. Ты сам вводишь свой API-ключ.
- **Стиль общения:** Вежливый, с иронией, в духе Джарвиса из Iron Man.

## 🛠️ Технологический стек

- **Язык:** Python
- **LLM:** Groq API (Llama 3.3 70B)
- **Граф:** NetworkX (хранение в JSON)
- **Визуализация:** Obsidian (Markdown + wiki-ссылки)
- **Интерфейс (в разработке):** CustomTkinter
